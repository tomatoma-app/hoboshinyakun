# ほぼしんや君 — ブラウザー試作

Excelの時間割をブラウザー内で編集・検索する試作です。

## 使い方

公開ページをEdgeまたはChromeで開き、「Excelを読み込む」で対応する時間割ファイルを選びます。
条件登録 → 変更開始 → 候補を確定 → Excelを保存、の順で使います。
起動用アプリのダウンロード・インストールは不要です。

## データについて

時間割は利用者のブラウザー内で処理されます。時間割や先生名を外部送信する処理はありません。
このリポジトリには、先生名入りのExcelや検証用データを含めていません。
初回起動時はPyodideの実行部品をjsDelivrから読み込むため、インターネット接続が必要です。
タブを閉じる前に、変更結果をExcelに保存してください。

## 試作の範囲

空き指定、自習対応、固定条件、検索、候補の確定、Excel保存に対応します。
通常版の全操作を移植した完成版ではありません。
検索処理は通常版と同じPythonコードを使用しますが、処理速度はPCやブラウザーにより異なります。

## GitHub Pages

Settings → Pages → Deploy from a branch → main / (root) で公開します。
`.nojekyll` により静的ファイルをそのまま配信します。
